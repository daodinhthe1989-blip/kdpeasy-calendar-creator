# KDPEasy Calendar Creator

Part of the KDPEasy Suite — free tools for KDP creators.

Generate a print-ready 12-month calendar PDF in seconds. Pick a year, page size, color theme, and week start day, then download a KDP-ready interior file.

## Features (v1)
- Year-specific 12-month calendar
- Week starts Sunday or Monday
- KDP trim size presets: Letter (8.5x11), 8x10, 6x9, A4, A5
- 4 color themes: Indigo Classic, Emerald Fresh, Sunset Warm, Mono Minimal
- Optional note-line in each day cell
- Optional cover page with custom title

## Planned for v2
- Evergreen (undated, reusable across years) calendars
- Holiday markers
- Habit tracker section
- Custom illustrations per month

## Stack
Streamlit + fpdf2 (pure Python, no system dependencies — runs free on Streamlit Cloud, no paid API used).

Password-protected, same pattern as the rest of the KDPEasy Suite.
